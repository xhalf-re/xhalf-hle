# Unicorn source changes

These patches modify GPL-2.0 Unicorn/Unicorn.js code and are distributed under its original GPL-2.0 terms. The original upstream notices and complete license files are retained by the build.

`unicorn-helper-temporaries.patch` releases each TCI adapter argument temporary after its call operation has been emitted. The pinned Unicorn.js adapter widened every narrow helper argument into a new i64 temporary and never freed it. A basic block with many helper calls exhausted the fixed TCG temporary array and corrupted translator state. This changes translator lifetime bookkeeping; it does not skip guest instructions, ASSERTs or hardware behavior.

The synthetic ARM `helper_stress` fixture exercises a single block with 160 hooked stores. The real DAT boot is a separate private gate; passing this synthetic test alone does not establish real-firmware compatibility.

`unicorn-arm-system-registers.patch` adds an opt-in, per-engine external counter and MPIDR identity at the existing ARM CP15 handlers. It restores generic timer CVAL/control writes, signed TVAL, read-only ISTATUS and level outputs without wall-clock reads or firmware-address hooks. `_xhle_arm_clock_configure` initializes the board interface and `_xhle_arm_clock_advance` updates its counter and returns the five timer output levels. The board routes those levels to its GIC. CPU-context restoration preserves the external counter and timer programming, so injected input calls cannot rewind hardware time or undo timer writes. Engines that do not enable this interface keep their default counter/MPIDR behavior. Synthetic relocated ARM/Thumb programs cover reads, expiry, masking, reprogramming, virtual timers and context restoration; real-firmware acceptance is separate.

The same ARM patch exposes an external IRQ line through `_xhle_arm_set_irq`. QEMU samples it at TB entry, including cached direct chains, and uses its architectural exception handler. A marker distinguishes TB-entry checks from checks inside memory/code hooks so MMIO accesses finish before an IRQ is taken. CPSR masking, VBAR, high vectors, SCTLR.TE, banked registers and exception returns use the CPU model. `_xhle_arm_is_waiting` exposes WFI waiting for external work. The independently written `slice.c` advances the board counter in C at TB boundaries, calls back only for due peripheral deadlines or changed timer outputs, and bounds halted time by the next event. No per-block JavaScript callback or firmware-address IRQ hook is needed.

Timer levels are cached until a register write, counter rollback or the next timer transition. Slice timing carries fractional counter ticks with integer arithmetic. These optimizations preserve the configured clock ratio and timer deadlines; they do not alter firmware instructions.
